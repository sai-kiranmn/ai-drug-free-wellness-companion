# AI Mental Wellness Companion for a Drug-Free Future

A hackathon project that combines AI-powered conversational support, mood check-ins, voice input/output, and emotional risk awareness to promote mental wellness and support a drug-free future.

## Core Features

- AI wellness chatbot
- Voice input from user
- Voice output from bot
- Mood and stress check-in
- Emotional risk-level analysis
- Drug-abuse prevention awareness
- Real-world social impact focus

## Tech Stack

- HTML
- CSS
- JavaScript for voice features
- Python
- FastAPI
- Jinja2 Templates
- AI API integration
